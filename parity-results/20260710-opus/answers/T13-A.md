**The 14.7% is wrong — it's not an annualized return.** Whoever wrote it took the total gain and divided by 3:

- Total growth: ₹50L → ₹72L = +44% over 3 years
- 44% ÷ 3 = 14.67% ≈ 14.7%

That's a simple average, which overstates the real compounded (annualized) return. The correct figure is the CAGR:

- CAGR = (72/50)^(1/3) − 1 = (1.44)^(1/3) − 1 = **12.9% per year**
- Check: ₹50L × 1.129³ = ₹72L ✓

So the line overstates annual performance by ~1.8 percentage points. In a fund deck this is the kind of thing a discerning LP (or a regulator) will catch, and "annual return" almost always means annualized/CAGR by convention — so it reads as either sloppy or inflated. Worth fixing.

**Crisper phrasings** (pick per what you want to emphasize):

- "₹50L → ₹72L in 3 years — a 12.9% annualized return (CAGR)."
- "Grew 44% over 3 years (12.9% CAGR), from ₹50L to ₹72L."
- If you specifically want to show the cumulative number: "₹50L → ₹72L over 3 years: +44% cumulative, 12.9% annualized."

I'd use the first — it's tight, labels the metric correctly, and "CAGR" signals rigor to investors.

One caveat: this treats it as a single lump sum held for 3 years. If there were contributions/withdrawals along the way, neither 12.9% nor 14.7% is right — you'd want an IRR/XIRR on the actual cashflows. Flagging in case the ₹50L wasn't a one-time starting figure.
