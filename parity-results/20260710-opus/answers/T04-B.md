The `monkeypatch.setattr` replaces `format_price` with a lambda that returns the constant `"₹1,234.50"` for *any* input. The assertion then checks that this constant equals that same constant. It cannot catch a regression, which is the one job a regression test has.

So the test is either (a) tautological — the bare name resolves to the stub, or (b) the monkeypatch is dead code — the bare name is the real unpatched import and the patch does nothing.
