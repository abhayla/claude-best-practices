## The 17 features (inventory)

**Hidden features in regular Claude:** (1) **Projects** — persistent instructions + docs; (2) **Artifacts** — live apps/SVG/charts/Mermaid in a side panel, free plan; (3) **Extended/Adaptive Thinking** — visible step-by-step reasoning for complex decisions; (4) **Memory** — builds a profile of you across chats (off by default).

**Role prompts (give Claude a job):** (5) personal psychologist (CBT-style, asks not validates); (6) **the hard mentor** — disables agreement, stress-tests assumptions; (7) personal trainer; (8) practice-a-hard-conversation (Claude plays the other side); (9) **devil's advocate** — "the full case against, the 3 realistic ways it fails."

**Product features:** (10) **Claude in Chrome** — sees + acts on your tab; (11) **Cowork** — desktop app with filesystem access; (12) **Scheduled Tasks** — runs on a cadence, saves output to a folder; (13) **Skills in Cowork** — install capabilities like plugins (Customize → Skills; Browse plugins → install); (14) **CLAUDE.md** — rules read automatically every session in Cowork/Claude Code; (15) **Claude Code** — reads codebase, writes/tests/fixes in a loop, VS Code/JetBrains/GitHub Actions; (16) **Claude Design** (claude.ai/design) — decks/prototypes/landing pages, exports PPTX/Canva/PDF/HTML; (17) **Prompt Caching** (dev) — `"cache_control":{"type":"ephemeral"}`, up to 90% cost cut on cached tokens, 5-min TTL, resets on each use.
