## What it says (the method, in 4 steps)

Thesis stated as a phone-trade-in analogy: *"the phone was never the treasure — the stuff inside was. Fable's magic isn't locked in a server; it's a set of thinking habits (figures out what you meant / breaks problems into pieces / double-checks its math / tells you when it's guessing). Habits can be written down, and anything written down can be handed to a cheaper AI."*

1. **Ask Fable 5 to write its own training guide** — not "how do you think?" (yields a useless essay) but a **recipe of exact steps**.
2. **Save the guide** (`continue` until finished) into a doc — "Fable 5 Brain Backup." *"The model leaves July 12. This file never does."*
3. **Load the backup into the free model via Projects** — New Project → paste the entire backup into Project **instructions** → start a chat set to **Opus 4.8**. "Every chat now reads Fable's habits before your words." *("You didn't copy the model — you copied the only part that was ever useful.")*
4. **Prove it worked with a TRAP TEST** — a question with a hidden error ("30% off $100 = $70, then 20% off = $56, so 44% off, NOT the 50% on the tag"). Plain Opus often agrees with the tag; the backup-loaded project should stop, redo the math, and catch it. Plus a "Prompt Box" of 7 reusable prompts (Brain Backup / Trap Test / Fix-It / Shrink-It / Make-It-Mine / Repeat-Task Interview / Health-Check) and a gated "Style Backup" prompt.
